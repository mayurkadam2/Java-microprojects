## About this repository

Project based learning is a very good approach to learn and apply the things, but creating a big project takes a while, so instead of creating a big time consuming project
I decided to create micro projects for what I learned so far. 

according to each level I get a constraints based problem statement, also I designed a acceptance test situation where I get a score 0-100 scale,
If my code get a score above 70 on the basis of various parameters I consider it as I learned things and push on git hub.

To get problem statement and design of the acceptance test I used AI, AI gives me a problem statement and according to that test conditions, test conditions
test for my code readability, all logic, scalability of my code. that help me to understand the correct use of the things.

This target is not small but dividing it in the chucks and doing consistently will achievable and help me to say confidently yes I know this concept of java
without going in any tutorial hell.
